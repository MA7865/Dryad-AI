# M2 — Vegetation & Anomaly Intelligence

**Project:** Dryad-AI / AI Forest Sentinel  
**Study Area:** Shaver Lake, California  
**Module:** Member 2 — Vegetation & Anomaly Intelligence  
**Status:** In progress — vegetation reference, satellite extraction and initial anomaly calculation completed  
**Last Updated:** 21 November 2026

## 1. Objective

The M2 module is responsible for identifying vegetation types and detecting unusual vegetation changes within the shared forest monitoring grid.

The module combines real LANDFIRE Existing Vegetation Type (EVT) data with Sentinel-2 satellite vegetation indices and historical seasonal observations.

The current implementation focuses on vegetation classification from reference data and exploratory anomaly analysis. Disease-specific prediction has not been implemented.

## 2. Study Area and Shared Grid

- Location: Shaver Lake, California
- Bounding box: [-119.50, 37.00, -119.25, 37.20]
- Number of patches: 2,061
- Patch size: 500 m × 500 m
- Shared grid: `data/grid.geojson`
- GeoJSON CRS: EPSG:4326
- LANDFIRE raster CRS: EPSG:26911
- LANDFIRE raster resolution: 30 m

The existing shared grid is reused without modification. All vegetation outputs preserve the original patch IDs.

## 3. Vegetation Reference Layer

**Dataset:** LANDFIRE LF2024 Existing Vegetation Type (EVT)

The official LANDFIRE EVT raster and associated raster attribute table were downloaded for the study area.

Vegetation classes were extracted by aggregating raster pixels within each shared grid polygon. The calculation records:

- Dominant vegetation class and its official LANDFIRE code
- Proportions of valid vegetation classes
- Valid-pixel count
- Approximate raster coverage fraction
- Data-quality status

**Results:**

| Metric | Result |
|---|---:|
| Total patches | 2,061 |
| Good coverage | 1,903 |
| Partial coverage | 153 |
| Missing coverage | 5 |
| EVT classes present in raster | 45 |

The most common dominant vegetation classes were:

- Northern and Central California Dry-Mesic Chaparral — 915 patches
- California Lower Montane Foothill Pine Woodland and Savanna — 377 patches
- Mediterranean California Dry-Mesic Mixed Conifer Forest and Woodland — 243 patches
- California Ruderal Grassland and Meadow — 130 patches
- Mediterranean California Mixed Oak Woodland — 126 patches

**Output:** `data/processed/vegetation/vegetation_reference.geojson`

This is a reference-derived classification, not an ML model prediction.

## 4. Google Earth Engine and Sentinel-2 Processing

Google Earth Engine authentication and project access were successfully configured.

**Satellite collection:** `COPERNICUS/S2_SR_HARMONIZED`

**Analysis period:** 1 June 2026 – 31 August 2026

The processing pipeline:

1. Retrieves imagery covering the Shaver Lake study area.
2. Filters scenes using cloud metadata.
3. Masks clouds and cloud shadows using the Scene Classification Layer (SCL).
4. Calculates NDVI and NDMI.
5. Builds median summer composites.
6. Aggregates indices over the shared 2,061 patches.

**Results:**

- Sentinel-2 images retrieved: 63
- Patches processed: 2,061
- Missing NDVI values: 0
- Missing NDMI values: 0

**Output:** `data/processed/vegetation/vegetation_features.csv`

The pipeline was tested using a real Earth Engine request and successfully returned satellite-derived values. The current extraction is reproducible from a script, rather than connected to automatic scheduled refreshes.

## 5. Historical Vegetation Anomaly Analysis

Historical features from Member 1 were reused:

`data/processed/m1_features_summers.csv`

The dataset contains 10,305 patch-year records covering 2022–2026.

An exploratory anomaly calculation was implemented using:

- Baseline years: 2022–2025
- Target year: 2026
- Historical NDVI and NDMI
- Regional reference medians from unburned forest patches

Each anomaly represents the difference between the target-year index and the patch's historical average, adjusted for the regional reference change.

**Results:**

| Metric | NDVI anomaly | NDMI anomaly |
|---|---:|---:|
| Valid records | 2,047 | 2,047 |
| Mean | +0.0265 | +0.0415 |
| Median | +0.0213 | +0.0378 |
| Minimum | -0.1374 | -0.1144 |
| Maximum | +0.1514 | +0.2247 |

Fourteen patches lack sufficient historical data and retain missing values.

Most patches show positive relative anomalies. Some patches show negative changes and may warrant further inspection.

These results are exploratory and are not confirmed disease or disturbance detections.

**Output:** `data/processed/vegetation/vegetation_anomalies.csv`

**Implementation:** `modules/vegetation/anomaly.py`

## 7. Known Limitations

- LANDFIRE EVT represents reference vegetation classification, not a live satellite prediction.
- The vegetation aggregation uses raster pixel-centre inclusion and approximate area-based coverage.
- Historic and newly extracted satellite features have different masking/processing conventions and are not directly mixed in the anomaly calculation.
- The reference adjustment uses unburned forest patches, while the current anomaly output also includes burned and nonforest patches.
- Only five historical summers are available.
- The anomaly method has not been validated against independent disturbance labels.
- No disease-specific or species-level diagnosis is supported.
- The FastAPI vegetation endpoint is not yet implemented.
