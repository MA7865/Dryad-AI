# M3 - Ignition Risk

## Status

Phase 1 scaffold is implemented. The M3 ignition-risk model is **not trained** and
the risk layer is a transparent stub with `risk_score: null`.

## Current files

- `modules/ignition_risk/interface.py`: public risk/stub/scenario/status functions
- `modules/ignition_risk/features.py`: feature foundation placeholder
- `modules/ignition_risk/scenario.py`: scenario foundation placeholder
- `modules/shared/grid.py`: shared grid loader and point-to-patch lookup
- `modules/shared/weather.py`: Open-Meteo forecast/archive client
- `scripts/build_patch_static_features.py`: per-patch terrain/fuel table builder
- `backend/app/api/ignition_risk.py`: risk and scenario routes
- `backend/app/api/weather.py`: forecast route

## Implemented API

- `GET /api/v1/layers/ignition-risk`
- `GET /api/v1/layers/ignition-risk/status`
- `GET /api/v1/patches/{patch_id}/ignition-risk`
- `GET /api/v1/weather/forecast?hours=48`
- `POST /api/v1/simulations/weather`

Map responses use EPSG:4326, UTC ISO 8601 timestamps, shared patch IDs, and the
M1/M4 property naming convention. There is no top-level `metadata` block and no
custom error `code` field.

## Weather

The shared client uses Open-Meteo forecast and archive endpoints. It requests
temperature, relative humidity, 10 m wind speed/gust/direction, precipitation,
and vapour-pressure deficit in UTC. Wind speed is requested in m/s.

Wind direction is returned FROM; `wind_toward_deg` is
`(FROM + 180) % 360`.

When VPD is unavailable, it is computed as:

`es = 0.6108 * exp(17.27 * T / (T + 237.3))`

`vpd = es * (1 - RH / 100)` kPa.

## Static features

The grid has 2,061 patches. `data/processed/patch_static_features.csv` contains
the generated static table.

- Elevation: mean LF2020 Elevation value in metres
- Slope: mean LF2020 Slope Degrees value
- Aspect: circular mean LF2020 Aspect; flat cells with no valid direction are `null`
- Fuel: most common LF2025 FBFM40 numeric code

The LANDFIRE rasters are stored locally under `data/raw/landfire/` and are
gitignored. The table builder is rerunnable; if required rasters are missing,
it fails with a clear path-specific error.

The downloaded data contains eight clipped LANDFIRE TIFF layers, one per folder.
Each folder has the TIFF, VAT DBF, metadata XML, output parameters, and GIS
sidecars. The folders total approximately 27 MB. Raw files must not be committed.

## Environment

The project venv is `.venv/`, created from Python 3.14.2. It contains Rasterio
1.5.2, GeoPandas 1.2.0, Pandas 3.1.1, NumPy 2.5.5, PyProj 3.8.0, Shapely 2.2.0,
FastAPI 0.165.0, Pydantic 2.14.4 and Pytest 9.2.0.

Rebuild the static table with:

```powershell
.venv\Scripts\python.exe scripts\build_patch_static_features.py
```

Windows application control has blocked a native Pydantic DLL in this venv during
one test run; the system Python remains a fallback for test validation.
